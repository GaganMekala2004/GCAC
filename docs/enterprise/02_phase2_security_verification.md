## 2. Explicit Scope Boundaries & Unenforced Surfaces (Phase 3 / Phase 4)

- **Native Copilot Agent Mode Tools:** Extension UI approval gates only enforce execution within `remediationEngine.js` / Extension Host commands; native Copilot Chat workspace edits or terminal runs initiated independently inside Copilot Chat remain governed by `.vscode/settings.json` command policies and Phase 3/4 platform controls.
- **Worktree vs Execution Sandbox (`SEC-07`):** Detached Git worktrees separate source files on disk only; build/test execution inside those worktrees still executes under developer OS user identity without network egress filtering until Phase 3 ephemeral containers/CI runners are deployed.
- **Enterprise Auth & WORM Evidence (`SEC-05` / `SEC-06`):** Local PoC approvals record `AUTHENTICATION_NOT_VERIFIED` and local evidence manifests are tamper-detectable only until Phase 4 Entra SSO Approval API and central WORM storage are integrated.
